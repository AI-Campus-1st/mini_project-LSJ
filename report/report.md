# 서울시 대중교통 및 생활인구 기반 출퇴근 혼잡도 분석 리포트

---

## 1. 대시보드가 답하는 질문

본 대시보드는 서울시 교통 및 도시 정책 실무자와 연구자를 타겟으로 하며, 어느 지역이 주거 기능에 비해 과도한 업무·상업적 부하를 떠안고 있는지 진단합니다. 이를 통해 한정된 행정력과 예산을 어느 교통 거점과 자치구에 우선 투입해야 하는지 객관적인 의사결정 근거를 제공합니다.

---

## 2. 데이터 수집

* **사용 API 목록**: 서울 열린데이터광장 오픈 API (자치구별 생활인구 데이터, 지하철 시간대별 승하차 인원 데이터)
* **수집 범위·기간·건수**: 25개 자치구 및 서울시 전체 합계 데이터를 포함한 월별·시간대별 레코드
* **수집 시 겪은 문제와 해결**: API 제공처마다 스키마 키 명칭이 혼재되어 발생하는 데이터 누락 문제를 다중 키 매핑 로직과 폴백 예외 처리를 통해 안정적으로 해결함.

---

## 3. 아키텍처

* **수집기/DB/대시보드 계층 구조**: 파이썬 수집기가 오픈 API 데이터를 가져와 MariaDB에 적재하고, 대시보드는 이를 읽기 전용으로 조회하는 단방향 아키텍처 적용
* **스키마 설계와 나눈 이유 / 원본·마트 분리 근거**: 원본 데이터의 오류 추적성을 높이고 대시보드 성능을 최적화하기 위해 원본 테이블과 집계 마트 테이블을 분리 설계함.
* **분리 검증 테스트 결과**: 26개 그룹(25개 자치구 + 서울 전체) 적재 테스트를 통해 정합성 검증 완료.

---

## 4. 대시보드 구성

* **화면 흐름과 스토리라인 설계 의도**: SCQA 프레임워크를 바탕으로 도심·강남구 인구 편중(문제) -> 주거·업무 불균형 진단(사분면) -> 출퇴근 승하차 압박 TOP 10(근거) 순으로 시각적 스토리텔링 구성
* **차트 선택 근거**: 자치구별 인구 규모 비교를 위해 파스텔톤 바 차트를 사용하고, 주거인구와 생활인구의 상관관계 분석을 위해 산점도(Scatter Plot)를 채택함.

---

## 5. 핵심 인사이트

주거인구 규모 대비 생활인구가 기형적으로 치솟는 지역의 격차를 좌표로 확인하며 베드타운 구조의 심각성을 실감했습니다. 또한 전체 인구 규모와 지하철 승하차 압박 순위가 완벽히 비례하지 않으며, 특정 환승역 중심(홍대입구, 잠실, 강남 등)으로 교통 부하가 폭발적으로 집중된다는 점을 데이터로 확인했습니다.
